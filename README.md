# Mahalanobis website

Hero and homepage work for mahalanobis.si.

- `hero-3d.html`: full-screen 3D hero. Every dot is a data element: dots fly into tables, joins run column to column and row to row, a pattern of amber rows forms across tables and lands outside the usual shape at the end. Built on three.js r128 from cdnjs. Open `hero-3d.html#p0` to `#p100` to jump to a point in the journey.
- `project/`: homepage wireframe (five visuals) and an earlier hero prototype, as Design canvas artboards.

All figures in the hero's glass notes are sample data.
